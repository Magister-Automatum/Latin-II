# Latin II

A resource for learning classical Latin, hosted on GitHub Pages.

## Setup for GitHub Pages

This site is configured to be hosted via GitHub Pages. To enable it:

1. Go to your repository settings
2. Navigate to **Pages** section
3. Select the branch (`main` or `gh-pages`) and root folder where the site files are located
4. Your site will be available at `https://username.github.io/Latin-II`

## Files Structure

- `index.html` - Home page
- `about.html` - About page
- `resources.html` - Resources page
- `styles.css` - Stylesheet
- `_config.yml` - GitHub Pages configuration
- `.nojekyll` - Tells GitHub Pages to skip Jekyll processing

## Local Testing

To test locally, you can use Python's built-in server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
